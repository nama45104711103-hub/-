# Google Play への配信手順

このアプリは PWA（インストールできるWebアプリ）として作ってある。
Google Play へは **TWA（Trusted Web Activity）** で配信する。Vercel に公開しているサイトを、
そのままアプリの中身として使う方式で、Android用のコードを書く必要はない。

## 1. 事前に用意するもの

| 項目 | 内容 |
|---|---|
| Google Play Console アカウント | 登録料 25ドル（1回限り）。本人確認（身分証・住所）あり |
| 公開URL | 本番の Vercel URL（この URL がアプリの中身になる） |
| プライバシーポリシーURL | `<本番URL>/privacy` |
| アプリアイコン 512×512 | `public/icons/icon-512.png` |
| フィーチャーグラフィック 1024×500 | ストア素材一式に同梱 |
| スクリーンショット | 1080×1920 を4枚、ストア素材一式に同梱 |

個人アカウントの場合、**12人以上のテスターによる14日間のクローズドテスト**を終えないと製品版に公開できない
（2023年11月以降に作成した個人アカウントが対象）。最新の条件は Play Console の案内に従う。

## 2. .aab（アプリファイル）を作る

### 方法A: PWABuilder（インストール不要・おすすめ）

1. https://www.pwabuilder.com/ を開く
2. 本番URLを入力して解析する
3. Android パッケージを生成してダウンロードする（`.aab` と署名情報が入っている）
4. ダウンロードした zip の中の **署名鍵と SHA-256 フィンガープリント**を控える

### 方法B: Bubblewrap（Java と Android SDK が必要）

```bash
npm install -g @bubblewrap/cli
bubblewrap init --manifest https://<本番URL>/manifest.webmanifest
bubblewrap build
```

## 3. ドメインとアプリを紐づける（必須）

これをやらないと、アプリの上部にブラウザのURLバーが出てしまう。

1. 手順2で得た署名証明書の **SHA-256 フィンガープリント**を用意する
   （Play App Signing を使う場合は、Play Console の「アプリの完全性」に表示される値を使う）
2. 次の内容で `public/.well-known/assetlinks.json` を作る

```json
[
  {
    "relation": ["delegate_permission/common.handle_all_urls"],
    "target": {
      "namespace": "android_app",
      "package_name": "<アプリのパッケージ名>",
      "sha256_cert_fingerprints": ["<SHA-256 フィンガープリント>"]
    }
  }
]
```

3. デプロイして `https://<本番URL>/.well-known/assetlinks.json` が開けることを確認する

## 4. ストアの掲載情報

**アプリ名**

```
クラゲカラーファインダー
```

**簡単な説明（80文字以内）**

```
好きな色を入力すると、その色に近い色のクラゲを25種のなかから探してくれるアプリです。
```

**詳しい説明**

```
好きな色を入れるだけで、その色に近い色のクラゲが見つかります。

「水色」「ピンク」「金色」のような色の名前でも、#7fcce3 のような色コードでも検索できます。
スマートフォンの色見本から選ぶこともできます。

■ 色の近さを数字で表示
入力した色とクラゲの色を、CIELAB色空間での色差（ΔE）をもとに比べ、
0〜100点の「近さ」として表示します。いちばん近いクラゲに続いて、2番目・3番目に近いクラゲも分かります。

■ 25種のクラゲ
ミズクラゲ、アカクラゲ、カツオノエボシ、オワンクラゲ、エチゼンクラゲなど、
日本の海でみられる種から深海のクラゲまで25種を収録。
学名、大きさ、すみか、生態の解説がついています。刺されると危険な種には注意書きを表示します。

■ 通信なしで動く
色の判定はすべて端末の中で計算しています。個人情報の収集はありません。広告も表示しません。

※ 掲載しているクラゲの画像は生成AIで作成したイメージです。
※ クラゲの色は個体差や光の当たり方で変わります。表示している色は目安です。
```

**カテゴリ**: 教育（または エンターテイメント）
**タグ**: 色、自然、海、図鑑、学習

## 5. Play Console での回答内容

| 質問 | 回答 |
|---|---|
| データセーフティ | **収集・共有ともになし**。検索した色コードを端末内（localStorage）に保存するのみ、外部送信なし |
| 広告の有無 | 広告なし |
| コンテンツレーティング | 全年齢向け（暴力・性的表現・ギャンブルなし） |
| ターゲット年齢 | 13歳以上（全年齢向けにする場合はファミリー向けポリシーの追加対応が必要） |
| アプリのアクセス権 | 制限なし（ログイン不要） |
| 政府機関向けアプリ | いいえ |

## 6. 審査で弾かれないための注意

Google は「Webサイトを包んだだけで機能が乏しいアプリ」を公開停止の対象にしている。
このアプリは次の条件を満たしているため、TWA として配信して問題ない状態にしてある。

- オフラインで起動し、検索も動く（サービスワーカーでキャッシュ）
- ブラウザのUIを出さずに全画面で動く（manifest の display: standalone）
- アプリ固有のアイコンとテーマカラーがある
- 端末内で完結する独自の機能（色差による検索）がある

## 7. 公開までの流れ

1. 本番URLにデプロイ（main にマージ）
2. PWABuilder で .aab を作る
3. assetlinks.json を設置して再デプロイ
4. Play Console でアプリを作成し、.aab をアップロード
5. ストア掲載情報・データセーフティ・レーティングを入力
6. クローズドテスト（12人・14日間）
7. 製品版として公開を申請
